# Lieferanten

## Lieferanten verwalten
„+ Neuer Lieferant“: Name ist Pflicht; außerdem Ansprechpartner, E-Mail, Telefon, Adresse, „Unsere Kundennummer beim Lieferanten“ und Notizen. Die E-Mail-Adresse wird für den Versand von Bestellungen genutzt, die Kundennummer steht auf der Bestellung. Lieferanten kannst du bei Artikeln hinterlegen; der Bestellvorschlag gruppiert danach. Rechnungen von Lieferanten erfasst du unter Buchhaltung → Eingangsrechnungen.
