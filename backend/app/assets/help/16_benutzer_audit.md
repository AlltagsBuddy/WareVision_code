# Benutzer und Audit-Log (nur Admin)

## Benutzer anlegen
Benutzer → „+ Neuer Benutzer“: Vorname, Nachname, E-Mail (Login), Rolle und Passwort (mindestens 6 Zeichen). Bei „Bearbeiten“ bleibt ein leeres Passwortfeld unverändert. „Deaktivieren“ sperrt den Zugang, „Freischalten“ hebt die Sperre auf.

## Modulberechtigungen
Das Suchfeld filtert die Liste nach Name, E-Mail oder Rolle. Für Nicht-Admins legst du je Modul fest, ob es sichtbar ist und ob geschrieben werden darf („Alle an“/„Alle aus“). Admins haben automatisch alle Rechte.

## Selbstregistrierung
Über den Link /register können sich neue Benutzer selbst anlegen; sie erhalten die Rolle „Werkstatt“ ohne Admin-Rechte. Das neue Konto ist zunächst gesperrt: Erst wenn ein Admin unter Benutzer auf „Freischalten“ klickt, ist eine Anmeldung möglich.

## Audit-Log
Das Änderungsprotokoll zeigt, wer wann was geändert hat (z. B. Rechnung ausgestellt, Kunde geändert, Inventur abgeschlossen). Filter nach Entität und Aktion; das Suchfeld durchsucht zusätzlich Benutzer (Name oder E-Mail) und die geänderten Werte (z. B. eine Rechnungsnummer). Einträge können nicht geändert werden.
